# Archive documentaire

Ces documents sont **historiques et aspirationnels** : d'anciens plans
d'intégration, rapports de « livraison » et états d'avancement qui décrivaient
l'*intention* plutôt que le système réel (revendications de complétude, modules
depuis neutralisés comme l'orchestrateur, roadmaps RL non réalisées, etc.).

Ils sont conservés pour l'historique mais **ne décrivent pas le système actuel**.
Pour l'état réel, voir à la racine de `docs/` :

- [`CANONICAL_ARCHITECTURE.md`](../CANONICAL_ARCHITECTURE.md) — le système réel (chemin canonique).
- [`SYSTEM_ASSESSMENT_AND_ROADMAP.md`](../SYSTEM_ASSESSMENT_AND_ROADMAP.md) — **source de vérité** de l'état et du plan.
- [`RUNBOOK_PAPER_TO_LIVE.md`](../RUNBOOK_PAPER_TO_LIVE.md) — mise en production.
