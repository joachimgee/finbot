⚠️  NOTES IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════

1. LAZY LOADING
   Les modules sont chargés à la demande (économie mémoire/temps).
   Certains nécessitent des paramètres spécifiques:
   • TechnicalFeatureEngine → OHLCV data
   • FundamentalFeatureEngine → fundamentals dict
   • SentimentFactorEngine → news_df
   • LSTMPredictor → params corrections nécessaires

2. FALLBACK MODE
   Si un module échoue, SignalFusionEngine continue avec les autres.
   Minimum 2 sources requises par défaut (configurable).

3. DÉPENDANCES MANQUANTES
   • TensorFlow → nécessaire pour LSTM (actuellement absent)
   • API Keys → Twitter, CoinGecko (warnings normaux)

4. PERFORMANCE
   • Fusion ~1.25s/symbole
   • 100 symboles → 2 min
   • 12K symboles → 4h (parallélisable)
