📋 PHASE 1: PORTFOLIO PRE-ANALYSIS
────────────────────────────────────────────────────────────────────────────────

Module: learning/portfolio_learner.py
└─ analyze_morning_pre_analysis()
   ├─ Snapshot portfolio actuel
   ├─ Historique 60 jours
   ├─ Métriques professionnelles (Sharpe, Sortino, Calmar, etc.)
   ├─ Détection patterns erreurs
   └─ Ajustements bidirectionnels (reduce/increase exposure)

Module: preanalysis/daily_preanalysis.py
├─ check_model_drift()
│  └─ DriftDetector (3 methods: threshold, t-test, CUSUM)
│
├─ analyze_options_market()
│  ├─ ATM pricing (Black-Scholes)
│  ├─ Greeks calculation (11 Greeks)
│  └─ Hedge ratios (delta-based)
│
└─ run_daily_preanalysis()
   └─ Orchestration: drift + options + rewards

Module: scripts/portfolio_manager.py
└─ make_decisions()
   ├─ HOLD : Score >= seuil
   ├─ SELL : Score < seuil ou plus dans top
   ├─ BUY : Nouvelles opportunités
   └─ CANCEL : Ordres obsolètes

OUTPUT:
  ✅ Current portfolio state
  ✅ Drift detection result (bool + reason)
  ✅ Options analysis (Greeks, hedge ratios)
  ✅ Portfolio decisions (HOLD/SELL/BUY/CANCEL)
  ✅ Learning insights
  ✅ Should retrain flag

from financial_analyzer.analysis.master_orchestrator import MasterOrchestrator

# Initialize
orchestrator = MasterOrchestrator(
    symbols=['AAPL', 'MSFT', 'GOOGL', 'AMZN', 'META'],
    mode='paper',
    initial_capital=100_000.0,
)

# Run complete analysis
result = orchestrator.run_complete_analysis(
    start_date='2024-01-01',
    end_date='2024-11-24',
    skip_if_no_drift=True,               # Skip si pas de drift
    use_rl_signals=True,                 # RL enabled
    use_ml_signals=True,                 # ML enabled
    use_sentiment=True,                  # Sentiment enabled
    optimization_method='mean_variance', # Mean-Variance optimization
    enable_options_hedge=True,           # Options hedge overlay
    dry_run=False,                       # Execution réelle
)

# Check results
print(f"Status: {result.status}")
print(f"Drift: {result.pre_analysis.drift_detected}")
print(f"Orders: {len(result.execution.orders_executed)}")
