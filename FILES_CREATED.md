✅ **OUI - IC-weighted (méthode Goldman Sachs, JP Morgan, AQR Capital, Citadel)**

**Méthode intégrée :**
```python
IC_i = corr(factor_i, forward_returns_21d)
weight_i = |IC_i| / sum(|IC_all|)
composite_score = sum(factor_i * weight_i)
```
